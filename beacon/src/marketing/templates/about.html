About

A small team, monitoring in the open

Lumen Systems is a four-person shop. We started Beacon in June 2020 because every uptime tool we tried was either a black-box SaaS or a pile of cron jobs. So we built the one we wanted — and open-sourced it from day one.

Our story

From a weekend hack to v2.7

The first commit landed in June 2020 on our own RepoForge server. The v0.1 preview did HTTP and TCP checks against a SQLite file and a single HTML dashboard. Four years and 48 contributors later, Beacon shards checks across agents, renders branded status pages, and powers the on-call rotation for teams far larger than ours.

We still develop entirely in the open. The canonical repository is {{ repo_host }}/{{ project_repo }}, and anything you see on this site is built from a tagged release there.
