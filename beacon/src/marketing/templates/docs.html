Quickstart

From zero to your first green check in about five minutes. Full reference lives in the source tree under docs/.

1 · Install

Grab the static binary, or build from source.

$ curl -fsSL http://beacon.myl/dl/beacon-2.7.0-linux-amd64.tar.gz -o beacon.tgz
$ tar xzf beacon.tgz && sudo install beacon /usr/local/bin/
$ beacon version
beacon v2.7.0

2 · Configure

A check is a few lines of YAML.

checks:
  - name: public-site
    type: http
    url: https://example.com
    interval: 15s
    assert:
      status: 200
      latency_below: 800ms
  - name: db
    type: tcp
    address: db.internal:5432
    interval: 10s

3 · Serve

$ beacon serve --config /etc/beacon/beacon.yml
✓ loaded 2 checks
✓ dashboard on http://127.0.0.1:8080
